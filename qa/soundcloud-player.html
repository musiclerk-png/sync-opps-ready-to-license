What to check

  1. Open this page in a signed-out or Incognito browser window.
  2. Try the private Share link. If the player rejects it, open the track on SoundCloud, choose Share → Embed, and paste SoundCloud's official embed code into the second field instead.
  3. Confirm the player shows the expected title and artist.
  4. Press Play. Confirm the recording plays for more than a few seconds.
  5. If the Embed tab or code is unavailable, check the track's Permissions → Display embed code settings. A private track does not necessarily have to be made public.

Privacy: This tool does not store pasted Share links or iframe codes, transmit them to the catalog database, add them to the address bar or send them to GitHub. Once you load the player, your browser passes the validated source reference to SoundCloud to play the track. Anyone obtaining an unlisted track's secret link may be able to listen, so do not use the source link in a public catalog until authorized.
